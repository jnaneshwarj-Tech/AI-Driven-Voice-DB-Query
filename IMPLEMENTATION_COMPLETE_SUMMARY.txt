🔧 TECHNICAL DETAILS
================================================================================

Database Columns Added (Auto-Created)
--------------------------------------
- admission_year (INT) - Corrected admission batch
- current_year (INT) - Academic year 1-4
- student_type (VARCHAR) - Regular/Lateral Entry
- estimated_semester (INT) - Current semester 1-8

Computed Fields (Never Stored)
-------------------------------
- graduation_year = admission_year + 4
- graduation_status = [ACTIVE|GRADUATED]

Key Formulas
------------
Regular Student:
  admission_batch = usn_year
  graduation_year = admission_batch + 4

Lateral Entry Student:
  admission_batch = usn_year - 1  ⚠️ CRITICAL VTU RULE
  graduation_year = admission_batch + 4

Graduation Status:
  if current_year >= graduation_year:
      status = "GRADUATED"
  else:
      status = "ACTIVE"
