## 🚀 How to Use Kannada Input

### One-Time Setup (Windows)

#### Step 1: Add Kannada Language
```
1. Press Windows + I (Settings)
2. Click: Time & Language
3. Click: Language & Region  
4. Click: Add a language
5. Search: Kannada
6. Select: ಕನ್ನಡ (Kannada)
7. Click: Next → Install
```

#### Step 2: Enable Kannada Keyboard
Once installed, you'll see a language indicator in your taskbar (usually says "ENG").

### Daily Usage

**Switch Keyboard:**
```
Press: Windows + Space
(Keep pressing to cycle through languages)
Select: ಕನ್ನಡ
```

**OR click the language icon** in the taskbar:
```
Click: ENG (taskbar)
Select: ಕನ್ನಡ - Kannada
```

**Type in Kannada!**
- Your keyboard now types Kannada directly
- Works in ALL applications (not just this app)
- Native, reliable, zero bugs

## 🔧 Troubleshooting

### Problem: Can't find Kannada in language list
**Solution:**
- Windows 10/11: Go to Settings → Time & Language → Language
- Search "Kannada" carefully (spelling matters)
- Make sure you have internet during install

### Problem: Keyboard won't switch
**Solution:**
- Try: Windows + Space (keep pressing)
- OR: Click "ENG" in taskbar
- Make sure Kannada is installed (should see "ಕನ್ನಡ" in language list)

### Problem: Typing gibberish
**Solution:**
- Make sure you selected "ಕನ್ನಡ" not just "Kannada English"
- Try: Windows + Space again
- Restart computer if needed

### Problem: Works but shows squares
**Solution:**
- Install Kannada fonts
- Usually auto-installs with language pack
- Restart browser
