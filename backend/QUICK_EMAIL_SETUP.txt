🚀 GMAIL SETUP (Most Common - 5 Steps)

1️⃣  Enable 2-Step Verification:
    → https://myaccount.google.com/security
    → Click "2-Step Verification" → Follow wizard

2️⃣  Generate App Password:
    → https://myaccount.google.com/apppasswords
    → Select: Mail → Other → "AI Database"
    → Copy 16-character password (example: abcd efgh ijkl mnop)
    → Remove spaces: abcdefghijklmnop

3️⃣  Open Backend .env File:
    → Location: C:\Users\manoj\Desktop\major\backend\.env

4️⃣  Update These Lines:
    MAIL_USERNAME=your_email@gmail.com
    MAIL_PASSWORD=abcdefghijklmnop    ← Your 16-char App Password (NO SPACES!)
    MAIL_FROM=your_email@gmail.com

5️⃣  Restart Backend Server:
    → Press Ctrl+C to stop current server
    → Run: python main.py
    → Test "Forgot Password" feature

🔧 TROUBLESHOOTING:

❌ "SMTP authentication failed"
   → Using regular Gmail password instead of App Password
   → Solution: Generate App Password at myaccount.google.com/apppasswords

❌ Still seeing console OTP after configuration
   → Empty/whitespace in MAIL_USERNAME or MAIL_PASSWORD
   → Solution: Verify both have values, restart server

❌ Emails going to spam
   → Normal for first few emails
   → Solution: Add sender to contacts, mark as "Not Spam"

❌ Network timeout
   → Firewall blocking port 587
   → Solution: Check network settings or try port 465
